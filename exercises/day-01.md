# Day 1: Workflow fundamentals
## Objective
Complete practical exercises for **workflow fundamentals**.
## Exercises
- [ ] Run the workflow manually.
- [ ] Change one step name and rerun it.

- [ ] The job runs on `ubuntu-latest`.
- [ ] `actions/checkout` places repository files in the workspace.
- [ ] A push changing only README should not trigger after the path restriction.
