# Day 4: Secrets and permissions
## Objective
Complete practical exercises for **secrets and permissions**.
## Exercises
- [ ] Create harmless `LAB_SECRET`.

- [ ] `GH_TOKEN` is required by GitHub CLI in the workflow.
- [ ] The `permissions` key controls token capabilities.
