# Day 14: Debugging and assessment
## Objective
Complete practical exercises for **debugging and assessment**.
## Exercises
- [ ] Run with failure enabled.
- [ ] Inspect annotations and summary.
- [ ] Set repository variable `ACTIONS_STEP_DEBUG=true` and rerun.
- [ ] Optionally set `ACTIONS_RUNNER_DEBUG=true` and download logs.
- [ ] Rerun failed jobs, then run with failure disabled.

## Verification criteria
- [ ] Step debug increases step-log detail.
- [ ] Runner debug produces runner and worker diagnostics.
